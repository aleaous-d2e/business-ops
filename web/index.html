看板说明与数据口径

看板给谁用
  • 业务负责人 / 销售总监：30 秒判断本月销售完成率、哪个区域/品类在拖后腿、毛利是否健康。
  • 运营与销售团队：定位到具体客户和异常订单，作为下周跟进和催款的清单。
  • 供应链 / 财务：监控滞销库存资金占用，以及高退款、负毛利等异常财务风险。
核心指标口径
  • 销售额 = 数量 × 单价 × (1 - 折扣)
  • 毛利 = 销售额 - 成本；毛利率 = 毛利 / 销售额
  • 销售完成率 = 销售额 / 目标（注：目标仅按“月份×区域”下发，筛选渠道/品类时前端不计算完成率，避免分母失真）
  • 异常订单 = 毛利率 < 0 或 折扣 > 30% 或 退款 > 销售额的 50%
  • 库存周转天数 = 当前库存 / (近 30 天销量 / 30)
  • 折扣分桶：0-10% / 10-20% / 20-30% / 30-40% / ≥40%；退款分桶：无退款 / 0-5% / 5-10% / 10-50% / ≥50%

*本页展示为 Python 生成的脱敏模拟数据，不涉及真实商业信息。
