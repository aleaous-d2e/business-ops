# 销售经营分析看板（模拟数据）

## 一、 项目背景与定位
**目标**：面向中小商贸 / 批发 / 零售 / 物流企业，帮助业务负责人和 HR 在 30 秒内看懂：**你会取数、会定口径、会做看板、会解释业务**。
**业务场景**：基于商贸批发订单数据（涵盖渠道、品类、区域、客户等级），构建从宏观 KPI 到微观异常订单的全链路分析。页面采用现代高阶 BI 大屏视觉风格（深蓝渐变、弥散阴影、双轴图表）。

看板致力于回答 4 个核心业务问题：
1. 本月销售完成率多少？趋势怎么样？
2. 哪些客户 / 区域 / 品类 / 渠道在拖后腿？
3. 毛利和费用是否健康？客户结构与折扣策略是否合理？
4. 哪些库存和订单异常需要处理？

## 二、 看板核心模块（高阶 BI 图表）
- **顶部 KPI 卡片**：销售额、毛利、毛利率、订单数、客单价、销售完成率（带高级 SVG 图标与状态预警）。
- **全局联动筛选**：支持按「日期范围、区域、渠道、品类」多维任意组合联动。
- **业绩达成与毛利趋势**：双轴复合图（销售额渐变柱 + 毛利率折线 + 目标虚线与面积填充）。
- **区域与品类结构**：中心带“总销售额”的环形图，直观展示营收构成。
- **区域与品类健康度**：带背景槽的横向进度条，通过红/黄/蓝动态渐变，直观对比目标完成率与毛利健康度。
- **渠道业绩分析**：销售额与毛利率对比双轴图，识别高效与低效渠道。
- **销售目标达成仪表盘**：半圆仪表盘实时展示整体目标进度。
- **客户等级业绩结构**：分析“战略 / 重点 / 普通”客户的销售额与毛利率差异。
- **折扣与退款健康度分布**：双柱状图展示订单在各折扣区间与退款区间的风险长尾。
- **渠道 × 品类毛利热力图**：交叉分析矩阵，红色代表毛利告急，绿色代表健康，精准定位降本增效点。
- **异常订单监控**：内置 Tab 切换组件（全部 / 仅负毛利 / 仅高折扣 / 仅高退款），快速定位问题。
- **库存预警与客户 TOP10**：明细表展示高优处理清单。

## 三、 数据说明
使用 Python 生成的 **4200+ 行模拟 / 脱敏订单数据**，覆盖 2026-01-01 至 2026-10-31，包含以下六张表：
- `raw_orders.csv`：订单明细（故意埋入负毛利、高折扣、高退款等异常数据）
- `dim_customer.csv`：客户维度（30个客户、等级、合作开始日期）
- `dim_product.csv`：商品维度（20个SKU、4个品类、参考成本）
- `dim_region.csv`：区域维度（华南/华东/华北/西南，及下属城市）
- `target.csv`：按月 × 区域下发的销售目标
- `inventory.csv`：当前库存与近 30 天销量

*声明：数据为算法生成的模拟脱敏数据，不涉及任何真实企业信息。*

## 四、 核心指标口径（防坑逻辑）
| 指标 | 计算口径 |
| :--- | :--- |
| **销售额** | `SUM(qty * unit_price * (1 - discount))` |
| **毛利 / 毛利率** | `销售额 - SUM(qty * cost)`；`毛利率 = 毛利 / 销售额` |
| **订单数 / 客单价** | `COUNT(DISTINCT order_id)`；`销售额 / 订单数` |
| **销售完成率** | `实际销售额 / 目标销售额` |
| **退款率** | `SUM(refund_amount) / 销售额` |
| **库存周转天数** | `当前库存 / (近30天销量 / 30)` |
| **滞销 SKU** | `近30天销量 = 0 且 当前库存 > 0` |
| **异常订单** | `毛利率 < 0` 或 `折扣 > 30%` 或 `退款 > 销售额 * 50%` |

> ⚠️ **口径防坑**：目标数据仅下发到「月份 × 区域」。如果前端筛选了「渠道」或「品类」，前端会**自动拦截并置空（—）销售完成率**，避免出现“分子变小、分母不变”的虚假完成率误导业务。

## 五、 数据处理与性能设计
1. **ETL 清洗与主数据修正**：以 `order_id` 去重；缺失单价/数量的脏数据剔除；订单表的区域强制与 `dim_customer` 对齐，防止跨区统计混乱。
2. **保留异常资产**：折扣 > 30% 的订单不直接删除，而是保留供前端异常监控使用。
3. **纯静态极速联动**：后端（Pandas）预聚合出 `dashboard.json` 用于首屏渲染；同时导出底层 `order_facts.json` 明细。前端切换筛选器时，直接在浏览器内存中对 JSON 进行极速重新聚合，实现了**零后端请求的毫秒级联动**。

## 六、 业务发现结论示例
1. **区域异常**：将日期筛选到 `2026-09` 且区域选「华东」，可发现销售完成率仅 **78%**，为全年最低，需复盘该区域的批发客户流失情况。
2. **品类风险**：查看「渠道 × 品类毛利热力图」，若发现“手机配件”在“批发”渠道呈现深红色，说明该品类在批发端基本不赚钱，需调整供货价或压缩成本。
3. **折扣失控**：查看「折扣与退款健康度」，若 `≥40%` 折扣分桶的订单数出现异常长尾，提示需严查大额折扣审批流程。
4. **资金占用**：发现 `SKU019`、`SKU020` 近 30 天无销量，但合计积压了 205 件库存，建议立刻清仓释放资金。
